CyDoc is a local documentation library and an embeddable web viewer. Start with the [quickstart guide](doc:quickstart).

Prefer writing with an editor? [CyDoc Studio](doc:studio#start) provides visual and Markdown editing, a complete example project, optional Git and local account-free use. Published manuals keep working independently of the editor.
