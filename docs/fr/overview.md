CyDoc est une bibliothèque de documentation locale et un lecteur web embarquable. Commencez par le [guide de démarrage](doc:quickstart).

Vous préférez écrire avec un éditeur ? [CyDoc Studio](doc:studio#start) propose une édition visuelle et Markdown, un projet d’exemple complet, Git facultatif et une utilisation locale sans compte. Les documentations publiées fonctionnent indépendamment de l’éditeur.
