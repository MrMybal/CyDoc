Ouvrez l’icône **Mon espace** dans l’en-tête pour retrouver vos favoris et pages récentes. Le cœur à côté du titre ajoute la page aux favoris. **Mes notes sur cette page** conserve vos remarques privées et permet leur export depuis Mon espace.

La position de lecture est mémorisée. Lorsque vous revenez sur une page, **Reprendre ma lecture** sous la description de la page vous ramène à cette position. Un lien explicite vers une section ou un média conserve sa priorité.

Les données restent dans le stockage de votre navigateur ou WebView. Si ce stockage est indisponible, vos notes et favoris restent disponibles entre les pages pendant la session de lecture courante. Le lecteur vous demande de les exporter avant fermeture. Le JSON téléchargé conserve une copie de vos données ; cette version ne propose pas de commande d’import. `storageId` permet à l’application de choisir son espace de données.
